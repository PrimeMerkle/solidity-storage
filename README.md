# Solidity Storage Contract

My first Solidity smart contract built while learning blockchain and Ethereum development.

##  About the Project

This is a simple Storage smart contract that allows a user to:

- Store a number
- Retrieve the stored number

##  How It Works

The contract contains a state variable called `number`.

The `store()` function changes the stored number.

The `retrieve()` function reads and returns the current stored number.

### Example

```text
store(50)
     ↓
number = 50
     ↓
retrieve()
     ↓
50
